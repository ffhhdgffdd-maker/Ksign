# اعتماد repo.p3nd.fun

النطاق الرئيسي: https://repo.p3nd.fun

## الرفع
ارفع محتويات هذه الحزمة إلى public_html الخاص بالنطاق، مع الحفاظ على بيانات السيرفر الحالية داخل data وsign/data وprivate وأي ملفات شهادات. لا تستبدل ملفات بيانات السيرفر بنسخة قديمة إذا حدثت عليها تعديلات بعد أخذ النسخة.

فعّل HTTPS وPHP 8.1 أو أحدث وامتداد cURL. فعّل إعادة كتابة Apache عبر .htaccess.

## الروابط
- / : واجهة الموقع الحالية
- /sources.php : صفحة المصدرين وقوائم التطبيقات
- /fakegps.json : 66 تطبيقًا
- /ipa-plus.json : 87 تطبيقًا
- /source.php : مصدر التطبيقات المحلية في لوحة التحكم
- /admin/login.php : لوحة التحكم
- /api/certificates/public.php?certificate_id=ID : بوابة الشهادات المستخدمة في التطبيق

## التحقق
افتح رابطَي JSON وصفحة المصادر. جرّب معرف شهادة صالحًا تملكه. تحتاج خدمة الشهادات إلى اتصال السيرفر بمزوّدها المعرّف في config.php؛ لم يتم نقل ملكية الشهادات أو ملفات تطبيقات الطرف الثالث إلى هذه الاستضافة.

التطبيق يبدأ باستخدام روابط هذا النطاق بعد تثبيت البناء الجديد. ملفات IPA الخارجية ما زالت تُنزّل من مزوديها الأصليين. الحزمة جاهزة للرفع، ولم يتم نشرها على حساب الاستضافة من هذه الجلسة.
